# 文档编辑器滚动与交互动效设计

日期：2026-08-11

状态：已确认，待实施

## 1. 背景与目标

当前项目已经具备 Vue 3 + Tiptap 的三栏文档编辑器。现有页面的信息架构和业务流程保持不变，但正文区域在内容较长时无法稳定地按内容长度滚动查看，章节操作栏与正文之间的空间关系也不够稳定。按钮、菜单、章节切换和状态反馈缺少统一的节奏，导致操作感偏即时和生硬。

本次改造面向工程研发人员，继续使用深色工业工作台的视觉语言，目标是：

- 让正文区域成为可独立、连续、完整的滚动阅读区域。
- 让长正文、长表格、待补充信息和架构图都能被访问。
- 让章节切换、保存、重新生成、确认、导出和引用定位具备克制的缓冲反馈。
- 让章节操作栏和编辑工具栏在当前窗口尺寸及窄窗口下保持稳定对齐。
- 不改变后端 API、业务数据结构、生成链路和来源资料约束。

## 2. 范围

### 包含

- 三栏编辑器的高度、宽度和溢出边界修正。
- 富文本正文容器的纵向滚动与宽表格横向滚动。
- 章节操作栏的稳定布局和顶部保持关系。
- 工具栏分组、换行与控件对齐优化。
- 页面切换、章节切换、菜单/弹层、按钮状态和定位高亮的轻量动效。
- `prefers-reduced-motion` 下的降级表现。
- 浏览器级验证及前端构建验证。

### 不包含

- 不修改后端 API 或数据库模型。
- 不修改 Tiptap 文档内容格式和导出逻辑。
- 不引入新的动画库、滚动库或状态管理库。
- 不重做项目列表、向导和模板配置页面的业务结构。
- 不添加持续漂浮、强弹性或影响文字输入节奏的动画。

## 3. 设计方向

采用“轻动效 + 状态缓冲”的混合方案：

1. 使用 CSS 过渡统一按钮、工具栏、弹层、章节项、引用卡片和状态标签的交互节奏，时长主要控制在 160–280ms。
2. 在编辑器状态层增加页面切换、章节正文轻量淡入、操作中的活动指示和引用/批注定位高亮。
3. 页面级转场保持轻量淡入淡出，不使用明显的滑入或缩放，避免打断连续编辑。

视觉上继续使用当前深色工业工作台和单一蓝色主操作色；不引入渐变背景、装饰性粒子或强烈科技特效。

## 4. 结构设计

### 4.1 编辑器高度与滚动传递链

编辑器外壳、三栏网格、内容面板和正文容器需要明确传递可收缩高度：

```text
editor-shell       height/min-height + overflow hidden
  editor-body      flex: 1 + min-height: 0 + min-width: 0
    content-panel  display: flex + min-height: 0 + min-width: 0
      editor-content flex: 1 + min-height: 0 + overflow: auto
        word-page   width: min(100%, 800px) + box-sizing: border-box
```

正文容器设置 `overscroll-behavior: contain`、`scrollbar-gutter: stable` 和平滑滚动行为，避免滚动事件穿透到页面或滚动条出现时发生横向抖动。正文容器需要支持横向溢出，以便宽表格在窄窗口中完整访问。

章节操作栏与正文滚动容器分离：操作栏保持在内容面板顶部，正文在下方独立滚动。正文区域增加可聚焦语义和滚动区域标签，方便键盘操作和辅助技术识别。

### 4.2 布局对齐

- 章节标题和操作按钮使用同一条 flex 对齐轴，标题允许收缩并显示省略号。
- 操作按钮统一最小高度、内边距、禁用透明度和图标/文字基线。
- 工具栏按功能组保留分隔关系，允许换行但不改变控件高度。
- 弹层锚定到所属按钮，避免随工具栏换行后出现在不可见区域。

## 5. 交互与动效

### 5.1 页面与章节

- 路由页面使用短暂的淡入淡出过渡，避免整页瞬时替换。
- 章节切换不重新创建编辑器实例；保留当前编辑能力，只对正文视图添加短暂的离场/进入状态。
- 章节内容更新后保持合理的滚动起点，引用或批注定位仍使用平滑滚动。

### 5.2 操作状态

- 保存中、重新生成中、确认中和导出中继续使用明确的文字状态。
- 在内容面板或操作栏附近增加不抢焦点的活动指示，让用户知道操作仍在进行。
- 成功、失败和待确认状态不使用假成功动画；失败继续显示真实错误信息。
- 现有导出进度遮罩保留，只统一其进出和降级动效。

### 5.3 定位反馈

- 批注和引用定位使用 `scrollIntoView({ behavior: 'smooth' })`。
- 定位后的目标文本或卡片增加短暂的边框/背景高亮，完成后自动恢复。
- 找不到精确原文时保留现有提示，不以动画掩盖定位失败。

### 5.4 动效降级

当用户设置 `prefers-reduced-motion: reduce` 时：

- 页面和章节淡入立即完成。
- 菜单、弹层和提示取消位移动画，仅保留状态变化。
- 定位滚动切换为瞬时滚动。
- 处理中状态保留文字和静态标记，不显示持续循环动画。

## 6. 文件与实现边界

预期修改范围：

- `frontend/src/App.vue`：页面级过渡包装。
- `frontend/src/pages/DocEditor.vue`：编辑器状态类、章节切换反馈和可访问语义。

- `frontend/src/styles/editor-refresh.css` 或新增同职责的编辑器交互样式：滚动边界、对齐、过渡和动效降级。

不修改 API 文件、后端服务、数据库迁移及源文件存储逻辑。

## 7. 验收与失败处理

### 功能验收

1. 打开 `0fd81e7b05a349328d117c1ce5c38459` 文档，富文本区域可以随正文长度上下滚动。
2. 正文下方的待补充信息、架构图和长表格不会被内容面板裁切。
3. 窄窗口下宽表格可以横向滚动，页面不出现无意的整体横向位移。
4. 章节操作栏、工具栏按钮和下拉菜单保持可见且对齐稳定。
5. 切换章节、保存、重新生成、确认、导出和引用定位均有清晰且克制的反馈。
6. 开启减少动画偏好后，核心操作仍可完成且没有持续动画。

### 工程验收

- `frontend/npm run build` 通过。
- 现有导出进度测试继续通过。
- 使用 Playwright CLI 打开当前文档页面，完成章节切换、正文滚动、工具栏菜单和引用定位的最小验证，并保存必要截图到 `output/playwright/`。

### 失败处理

- 如果正文仍无法滚动，优先检查外层高度链、`min-height: 0`、网格子项 `overflow` 和开发者工具中的实际滚动高度。
- 如果章节切换动画影响编辑器输入，取消正文离场阶段，仅保留进入淡入。
- 如果页面级转场导致路由组件状态重建，改为仅对页面壳层应用过渡，不改变组件 key。

## 8. 完成定义

正文滚动缺陷在目标文档中可复现地修复；操作栏和工具栏在目标窗口尺寸下视觉对齐；动效不会阻断编辑、定位和导出；前端构建及浏览器最小验收通过；改动范围保持在前端交互层。
