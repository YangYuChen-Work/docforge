# 侧栏品牌与运行状态信息收敛设计

## 背景

当前侧栏顶部使用 `DF / DOCFORGE / 项目文档工作台` 的三层品牌锁定组合，底部还展示运行环境与模型服务状态。用户反馈顶部表达偏 AI 产品化、底部状态卡片不需要在主导航中长期占位。

## 设计目标

- 侧栏顶部只保留业务品牌“徐工重型”。
- “徐工重型”使用楷书风格，形成更贴近企业与工程场景的识别感。
- 删除底部运行环境卡片及其模型服务状态文案。
- 保留侧栏导航、折叠、移动端菜单、主题切换和占位提示行为。

## 方案

### 顶部品牌

将现有 `brand-lockup` 内的 DF 方形标识和副标题全部移除，仅渲染一个品牌标题：

```html
<h1 class="nav-text brand-lockup" aria-label="徐工重型">
  <span class="brand-name">徐工重型</span>
</h1>
```

通过字体栈 `STKaiti`, `KaiTi`, `BiauKai`, `serif` 提供跨平台楷书回退。字号、行高和标题区域间距沿用现有侧栏比例，避免在折叠态和移动端改变导航布局。

### 底部状态

从 `AppSidebar.vue` 删除 `.sidebar-provider` 整个节点。同时移除仅服务于该节点的 `aiProvider`、`providerLabel`、`providerDetail` 和 `/health` 请求，避免页面继续为已不可见的运行状态发起请求。

主题切换按钮仍保持侧栏底部锚定，由现有 flex 布局自然占据剩余空间。

## 验收标准

1. 首页侧栏顶部可见“徐工重型”，不再出现 DF、DOCFORGE 或“项目文档工作台”品牌副标题。
2. “徐工重型”计算样式使用楷书字体栈中的字体。
3. 首页侧栏不再存在运行环境、真实模型服务、已连接本地文档生成服务等状态卡片或其请求逻辑。
4. 导航链接、侧栏折叠、移动端菜单和主题切换行为不受影响。
5. 侧栏相关静态回归检查通过，前端生产构建通过。

## 范围边界

本次只修改侧栏品牌展示与运行状态展示，不修改全局产品名称、页面标题、导航名称、后端健康检查接口或其他页面内容。
