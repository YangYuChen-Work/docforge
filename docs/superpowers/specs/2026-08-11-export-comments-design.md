# 三种格式导出批注设计

## 目标

保留现有 DOCX、PDF、XLSX 三种导出格式，并允许用户在每次导出时选择是否携带编辑器中的人工批注。

## 导出选项

- 前端先选择格式，再选择“不带批注”或“带批注”。
- API 请求增加 `include_comments: boolean`，缺省为 `false`，因此旧调用仍然是不带批注导出。
- `Export` 记录保存该选项，便于审计和查询。
- 已标记为“忽略”的批注不进入导出；待处理和已处理批注都保留。

## 三种格式的呈现

### DOCX

“带批注”时写入标准 Word comment part、批注范围和批注引用。用户可以在 Word 的审阅/批注功能中查看批注。批注根据 `target_text` 匹配导出后的正文 Run；原文已被人工修改、无法精确定位时，批注回退到对应章节标题，并在批注内容中保留原文和未定位提示。

### PDF

PDF 继续沿用 DOCX 渲染后由 LibreOffice 转换的链路。“带批注”时，在对应章节正文后追加醒目的可见批注块，包含批注原文、批示和已有定位信息；这样不依赖 PDF 阅读器是否支持 Word comment 注释层。

### XLSX

XLSX 继续使用“项目概览 + 文档目录 + 表格 Sheet”结构。“带批注”时，优先将批注附加到包含 `target_text` 的表格数据单元格，并新增“批注”清单 Sheet；正文批注或无法匹配到表格单元格的批注仍完整出现在清单中，并标记“未在表格中定位”。

## 验收标准

1. 三种格式入口仍可用，且每种格式都能选择带批注/不带批注。
2. DOCX 不带批注时不生成 comments part；带批注时 Word comment XML、范围和引用完整，常见办公软件可打开。
3. PDF 带批注时能在导出文本中看到批注块；不带批注时不追加批注块。
4. XLSX 带批注时能在匹配单元格查看批注，并在“批注”Sheet 查看全部可导出批注。
5. 导出失败仍保留失败记录和错误信息，不显示假成功。
