# 表格来源覆盖与双向联动设计

## 背景

章节正文中的来源标记目前依赖把 `Citation.source_excerpt` 作为纯文本在 Tiptap 文档中精确匹配。来源解析器对 DOCX/XLSX 表格保存的是包含 `headers`、`rows` 的 JSON 字符串，因此生成章节引用结构化表格时，正文表格没有可匹配的纯文本片段，导致表格级来源标记遗漏。

本需求要求：章节中凡能从已有引用和来源资料可靠追溯的表格，都尽可能显示来源文件名；来源文件名标记与右侧来源卡片保持双向联动；确实无法可靠定位来源时不虚构标注。

## 目标

1. 解析结构化表格引用，识别章节正文中的对应 Tiptap `table` 节点。
2. 在表格标题末尾显示“来源：文件名”；无标题时在表格节点后显示。
3. 点击表格来源标记时，右侧数据来源页签的对应卡片自动定位、高亮并闪烁。
4. 点击右侧来源卡片的“定位正文”时，正文滚动到对应表格，并保持表格及来源标记的激活状态。
5. 一个表格引用多个来源时，保留每个来源文件名标记；同一来源引用不产生重复标记。
6. 没有来源或无法形成可靠匹配时，不臆造来源；继续保留现有正文引用匹配和“未找到精确片段”的回退行为。

## 非目标

- 不修改章节 `content_json`，来源标记仍属于编辑器装饰层，不污染正文和 DOCX 导出内容。
- 不改变数据库 Citation 数据结构和来源解析格式。
- 不把没有引用证据的所有表格批量标记为任意来源。

## 方案

### 前端装饰层表格匹配

在 `ReferenceDecorations.ts` 中集中实现 `findCitationRange(editor, citation)`：

1. 先遍历当前 ProseMirror 文档，收集每个顶层或嵌套 `table` 节点的绝对范围和标准化单元格文本。
2. 对引用的 `source_excerpt` 尝试解析 JSON；支持对象内 `caption`、`headers`、`rows`，也支持递归提取数组和对象中的字符串值。
3. 使用去空白、大小写不敏感的标准化文本，对每个候选表格计算结构化值命中数。
   - 至少两个有辨识度的单元格值命中，或单个长度足够长的非数字值命中，才认为是可靠匹配。
   - 多个候选表格同时命中时选择得分最高者；最高分并列时放弃表格映射，避免误标。
4. 结构化引用匹配到表格时，优先生成表格级装饰，不再为同一引用在表格单元格内部生成重复的正文标记。
5. 对仍未映射到表格的引用，继续使用现有纯文本 `source_excerpt` 匹配逻辑。

### 标记位置和样式

- 如果表格前相邻段落是表格标题（文本以“表”开头或包含“表格”标题语义），来源 widget 放在标题段落末尾。
- 否则来源 widget 放在表格节点之后。
- 表格级引用使用 `source-table-marker` 和 `source-table-highlight` 类，沿用现有文件名标签、激活状态和点击回调。
- 同一表格按 `source_document_id` 去重，同一文件只显示一个文件名标记，并将点击关联到该文件在本章的首个引用卡片。

### 双向定位

- 表格标记点击：沿用现有 `onCitationSelect`，设置激活引用、打开数据来源页签，并调用 `focusCitationCard`。
- 来源卡片“定位正文”：`ContentPanel.focusCitation` 使用同一 `findCitationRange`，因此结构化表格引用也能滚动到表格；找不到可靠表格时保留现有章节正文回退提示。
- 选中的表格增加激活节点样式，来源 marker 同步使用 active 样式；右侧卡片继续使用现有 active/flash 状态。

## 代码边界

- `frontend/src/editor/ReferenceDecorations.ts`：增加表格收集、结构化引用解析、表格引用范围查找和表格 widget/node decoration。
- `frontend/src/components/ContentPanel.vue`：调用统一引用定位函数；补充表格来源标记和激活表格样式；不改变现有正文编辑行为。
- `frontend/src/styles/page-doc.css` 或 `ContentPanel.vue` 局部样式：保证标题/表格后的长文件名可换行，并使表格激活边界清晰。
- `frontend/tests/source-linkage.test.mjs`：增加静态回归检查，覆盖结构化 JSON 表格值、表格 marker、统一定位函数、卡片联动和样式。

## 验收标准

1. 结构化表格引用的 JSON 与正文表格内容一致时，表格标题或表格后出现完整来源文件名。
2. 一个章节内存在多个表格时，来源只标到内容匹配的表格，不因来源表编号与正文表编号不同而错误按序号映射。
3. 表格来源标记点击后，对应来源卡片具有 `active` 和 `source-card-flash` 状态。
4. 来源卡片定位表格引用时，正文对应表格具有 active 高亮并滚动可见。
5. 无法解析或无法唯一匹配的来源不会产生错误表格标记，且现有纯文本引用行为不回归。
6. 前端测试和构建通过，Python 回归测试不受影响。
