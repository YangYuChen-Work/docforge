# 侧栏品牌图标融合设计

## 目标

将侧栏左上角从单一文字标题升级为与系统背景融合、但仍醒目的企业标识区。视觉参考用户提供的徐工集团标识，但不直接复制完整商标或将中文文字交给图片模型绘制。

## 视觉方案

- 图标使用原创几何工业徽记：深蓝六边形外轮廓、白色工程结构负形、浅蓝向下箭头。
- 图标以透明 PNG 嵌入侧栏，不带白色底板，不产生图片矩形边界。
- 文字使用页面 HTML 文本“徐工重型”，字体栈为 `STKaiti`, `KaiTi`, `BiauKai`, `serif`，确保楷书字形清晰、可访问、可缩放。
- 展开态横向显示图标与文字；折叠态只保留图标，保持现有折叠宽度与恢复按钮行为。
- 通过现有主题变量控制文字与边框颜色，图标在深色和浅色背景中都保持识别度。

## 资源与实现边界

- 生成素材：`frontend/src/assets/xcmg-emblem.png`，仅包含原创图标，不包含文字。
- 中间的绿幕源图不作为产品资源使用。
- 修改范围限定为 `AppSidebar.vue`、`visual-system.css`、品牌回归测试和新增图标资源。
- 不修改导航、主题切换、折叠逻辑、页面标题或业务数据。

## 验收标准

1. 首页左上角展开态同时看到几何图标和“徐工重型”。
2. 左上角没有白底图片块，图标透明区域能显示系统背景。
3. “徐工重型”由 DOM 文本渲染，计算字体使用楷书字体栈。
4. 侧栏收起后图标仍可见，展开/收起按钮和导航可用。
5. 测试、生产构建和浏览器控制台检查通过。
